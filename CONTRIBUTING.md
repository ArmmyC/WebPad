# Contributing to WebPad

Thank you for helping make WebPad clearer and safer to use. This repository is WebPad's public project and community home. The application implementation and operational deployment configuration are maintained separately.

## Ways to help

- Report a reproducible public website problem in the [issue tracker](https://github.com/ArmmyC/WebPad/issues).
- Suggest an improvement to the public documentation or onboarding guidance.
- Correct an outdated public link or product explanation.
- Improve the public repository's community or security documentation.

## Before opening an issue

1. Describe the page or public behavior involved.
2. Include the smallest reproducible set of steps.
3. Link the relevant public URL when possible.
4. Avoid posting passwords, API tokens, private keys, verification codes, personal data, or private DNS/provider details.
5. Do not guess at security impact; use the private reporting path in [SECURITY.md](./SECURITY.md) for vulnerabilities.

## Documentation changes

Keep changes focused, factual, and easy to scan. Product boundaries matter: WebPad manages DNS and namespaces, while the destination platform hosts the site and manages its certificate.

The maintainers may close reports that require private source access, expose sensitive information, or cannot be verified from public behavior.
